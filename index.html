Hermes Bot

Hermes Bot is a personal automation assistant that connects a single user to their own Google account so the assistant can help manage their calendar, email and files on request.

What it does

  • Calendar: view, create, update and delete events in the calendars the user explicitly shares with the assistant account.
  • Gmail: search and read the user's own mail, and draft or send replies the user requests.
  • Drive: find, read, upload and organise files in the user's own Drive.

Who it is for

This application is built for and used by a single individual (its owner). The Google account it connects to grants access only to data that user owns. There are no other users and no third-party data processing. The assistant runs on the owner's own machine.

How data is handled

Google user data is accessed only on the owner's explicit request, processed locally on the owner's own systems, and is never sold or shared with third parties. See the Privacy Policy for details.
