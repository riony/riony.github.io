Privacy Policy - Hermes Bot

This privacy policy describes how Hermes Bot ("the application", "we") accesses, uses, stores and shares information belonging to the user who authorizes it. Hermes Bot is a personal assistant application used by a single individual.

Google user data we access

With the user's explicit consent, the application may access the following Google user data, depending on the scopes the user grants:

  • Google Calendar - calendars the user shares with the application account, including events, titles, times, locations and descriptions.
  • Gmail - the user's own messages and labels, for searching, reading and composing mail at the user's request.
  • Google Drive - the user's own files, for search, retrieval, upload and organisation at the user's request.

How we use the data

Data is used solely to perform the actions the user requests through the assistant interface, for example listing calendar events, retrieving an email, or sending a message the user has asked to send. Data is not used for advertising, profiling, or any purpose unrelated to the user's direct instructions.

How we store and protect the data

The application stores an OAuth token on the owner's own machine, protected by filesystem permissions. Google user data may be cached only as needed to complete the requested operation and is retained on the owner's own systems. The application does not operate a public server that stores other people's data.

Sharing and disclosure

We do not sell, rent, or share Google user data with third parties. Data is not used for training machine learning models. Google user data is not transferred to third parties unless required by law, and never for advertising purposes.

Google API Services User Data Policy

The application's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Retention and deletion

The user can revoke the application's access at any time at myaccount.google.com/permissions, which stops all further access. Locally cached data is deleted by the user by removing the application's data directory.
